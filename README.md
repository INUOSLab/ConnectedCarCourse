# 커넥티드카와 클라우드 컴퓨팅 공개 강의

커넥티드카 서비스의 백엔드가 되는 **퍼블릭 클라우드**를 개념부터 실습까지 여섯 번의 강의로 배우는 공개 강의입니다.
2025년 2학기 인천대학교 Cloud+X 학석사연계 융합전공 커넥티드카 PBL 수업에서 사용한 자료를 온라인 공개용으로 재구성했습니다.

- **강의자**: 인천대학교 김영필 교수
- **형식**: 강의 영상 (영상 링크로만 제공)
- **대상**: 클라우드를 처음 접하는 학부생·대학원생, 커넥티드카·IoT 서비스의 백엔드 구조가 궁금한 개발자
- **선수 지식**: 네트워크 기초(IP 주소, 포트), 리눅스 명령줄 기초 (필수는 아님)

## 실습에 대하여

- 3강부터 각 강의에 1~2개의 **웹 콘솔** 실습이 있으며, 여섯 실습은 '플릿 텔레매틱스 서비스'를 단계별로 만들어 가는 하나의 시나리오로 이어집니다.
- 특정 사업자의 콘솔 메뉴 위치가 아니라 AWS, Google Cloud, Microsoft Azure 등에 대해 어디서나 같은 흐름으로 따라 할 수 있습니다. 
- 실습 환경, 샘플 파일, 미리 구성된 환경을 전제로 하는 실습에 대한 자세한 안내는 [index.md의 실습 안내](index.md#실습-안내)를 보세요.

## 자료에 대하여

- 실제 수업은 AWS에서 제공하는 교육용 클라우드 플랫폼을 활용해 진행했습니다. 이 공개 자료는 해당 사업자가 제작·검수·후원한 것이 아니며, 특정 사업자에 의존하지 않도록 서비스 이름을 일반 명칭(가상 서버, 객체 스토리지, 관리형 관계형 DB, 가상 네트워크 등)으로 바꿨습니다.
- 슬라이드의 그림은 모두 이 강의를 위해 새로 그린 개념도입니다. 원본 수업에서 인용했던 보고서 그래프, 논문 그림, 콘솔 화면 캡처는 싣지 않았으며, 필요한 경우 출처만 글로 표기했습니다.
- 실습의 자원 이름과 플릿 텔레매틱스 시나리오, 실습 절차의 서술은 이 공개 강의를 위해 새로 구성한 것입니다.
- 참고 문헌과 실제 수업의 PBL 결과물 링크는 [index.md의 자료에 대하여](index.md#자료에-대하여)에 있습니다.
